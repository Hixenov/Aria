# 0.3.0 manual check

0.3.0 connects Aria to Spotify. None of it has been tried against the real Spotify: the
automated tests use a fake Spotify on the computer itself. This takes about 25 minutes and needs
a Spotify Premium account on the app's allow-list (developer.spotify.com, the app, Users and
Access), and the Spotify app open on a phone or on the computer. Each line says who verified it:

- **pending**: not verified by anyone yet. Replace it with `user` and the date, or write what went
  wrong.
- **agent**: run by the coding agent.

## 1. Connecting (5 minutes)

| Check | Who |
|-------|-----|
| Settings, Spotify, "Connect Spotify": the browser opens Spotify's sign-in page (accounts.spotify.com), and it asks for the permissions listed in PRIVACY | pending |
| Agree: the browser tab says you are connected to Aria; Settings shows "Connected as" with your name | pending |
| Windows: Credential Manager, Windows Credentials, has an entry for `Aria` / `spotify` | pending |
| Close Aria and start it again: Settings still shows you connected, and no browser opens | pending |
| Connect, then cancel in the browser ("Cancel" on Spotify's page): a notice says the sign-in was cancelled, and Settings offers to connect again | pending |
| With another program on port 43819 (for example `python -m http.server 43819`), "Connect Spotify": a notice says the port is in use; nothing hangs | pending |
