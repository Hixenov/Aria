## Windows

- [ ] Turning "Start with the system" on adds "Aria" to Task Manager's Startup tab (enabled).
- [ ] Logging out and in: Aria's window flashes at most for a moment, then only its tray icon
  is there and nothing plays; a click on the icon shows the window.
- [ ] Turning it off removes "Aria" from the Startup tab.
- [ ] Disabling Aria in Task Manager's Startup tab keeps it from starting, and Aria does not
  turn it back on (not even when its switch is turned off and on again).
- [ ] Starting Aria by hand, then logging in again while it runs (or running
  `aria.exe --autostart`): the second copy quits and nothing shows.
- [ ] Uninstalling removes the Startup entry.
- [ ] A portable Aria, moved to another folder and started once: the entry follows it.

## macOS

- [ ] Turning it on creates `~/Library/LaunchAgents/io.github.hixenov.aria.plist`; at login
  Aria starts with its icon in the menu bar.

## Linux

- [ ] Turning it on creates `~/.config/autostart/io.github.hixenov.aria.desktop`; at login
  Aria starts in the tray (KDE), or minimized (Wayland, or no tray).
