# 0.3.1 manual check

0.3.1 adds the full-screen record. The automated tests drive the mode in a simulated window;
nobody has looked at it in a real one yet. This takes about 15 minutes and needs a few local
tracks with embedded covers (one without a cover helps), and for section 4 a connected Spotify
account. Each line says who verified it:

- **pending**: not verified by anyone yet. Replace it with `user` and the date, or write what went
  wrong.
- **agent**: run by the coding agent.

## 1. Opening and closing (3 minutes)

| Check | Who |
|-------|-----|
| The button at the right end of the player bar (four corners) opens the mode; the window fills the screen, with no sidebar or bar | pending |
| "Exit full screen" (top right) closes it; the window is back to its size and place | pending |
| F11 opens it, and F11 again closes it | pending |
| Esc closes it; with the finish panel open, the first Esc closes only the panel | pending |
| With the window already full screen (or maximised) before opening, closing the mode leaves it as it was | pending |
| While the mode is open, Ctrl+1 to Ctrl+9 do not change pages; Space still plays and pauses | pending |
| Quit Aria (Alt+F4) while the mode is open, and start it again: the window is windowed, at its old size | pending |
| If Windows offers a way out of full screen other than Aria's (for example Win+Down), it closes the mode cleanly | pending |

## 2. The record (5 minutes)

| Check | Who |
|-------|-----|
| Playing: the record turns smoothly at 33⅓ rpm (one turn in 1.8 s), with no stutter | pending |
| Pause: it slows to a stop in under a second; play: it speeds up in about half a second | pending |
| The tonearm swings onto the outer grooves on play, and back to its rest on pause | pending |
| The cover sits on the label, sharp, and turns with the record; the sheen does not turn | pending |
| A track without a cover: the label is plain, and nothing looks broken | pending |
| A wide screen shows the sleeve with the cover and the record half out of it | pending |
| A tall or narrow window (for example half a screen wide, before opening) shows the record alone, whole enough to read | pending |
| Nothing playing: the mode says so, and the record is still | pending |

## 3. Finishes and controls (4 minutes)

| Check | Who |
