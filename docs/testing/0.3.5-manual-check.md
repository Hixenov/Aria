# 0.3.5 manual check

0.3.5 adds the update checker. The automated tests run against a local fake GitHub only; Aria has
not checked a real release, downloaded a real installer, or updated itself yet. The restart can
only be tried for real once a version after 0.3.5 is published. Each line says who verified it:

- **pending**: not verified by anyone yet. Replace it with `user` and the date, or write what went
  wrong.
- **agent**: done by the coding agent.

## 1. Asking first (2 minutes)

| Check | Who |
|-------|-----|
| First start of 0.3.5 (fresh install, and over 0.3.4): the card "Keep Aria up to date?" is at the top of the page | pending |
| Before answering, nothing reaches the network (for example, no connection to api.github.com in Resource Monitor) | pending |
| "Not now" hides the card for good, also after a restart; Settings, Updates shows the switch off | pending |
| "Turn on" hides the card; about 10 seconds later the Updates row says "Aria is up to date" | pending |
| A restart within a day does not check again (the row says "Not checked yet") | pending |

## 2. Settings, Updates (2 minutes)

| Check | Who |
|-------|-----|
| With the switch off, "Check for updates" checks once and shows the result | pending |
| With the network off, the row says "Couldn't check: no connection to GitHub" | pending |
| The texts read well in Russian and Armenian | pending |

## 3. A newer release (once a version after 0.3.5 is out)

| Check | Who |
|-------|-----|
| The installed Aria shows "Downloading … %", then "Aria <version> is ready", a notice, and "Restart to update" in the sidebar | pending |
| `%LOCALAPPDATA%\Aria\cache\updates` (or the cache folder in Settings, Advanced) holds the installer and its `.sha256` | pending |
| "Restart to update" closes Aria, the installer shows its progress, and the new Aria starts by itself | pending |
| The library, playlists and settings are all there after the update | pending |
| Quitting without clicking keeps the button; it is back on the next start without a new download | pending |
| A portable Aria and the loose `aria.exe` show "Aria <version> is out", and the button opens the release page | pending |
| macOS and Linux do the same | pending |
