# 0.3.2 manual check

0.3.2 adds the mini-player (and the record's speed slider). The automated tests draw the
mini-player inside the main window, as egui's test harness does with a second window; nobody has
opened it as a real window yet. This takes about 15 minutes and needs a few local tracks with
embedded covers, and for section 4 a connected Spotify account. Each line says who verified it:

- **pending**: not verified by anyone yet. Replace it with `user` and the date, or write what went
  wrong.
- **agent**: run by the coding agent.
