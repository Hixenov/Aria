# 0.4.0 manual check

0.4.0 adds media keys and the system's media controls. The automated tests run against a
stand-in for the system only; nobody has pressed a media key with Aria yet. This takes about 10
minutes. Each line says who verified it:

- **pending**: not verified by anyone yet. Replace it with `user` and the date, or write what went
  wrong.
- **agent**: done by the coding agent.
