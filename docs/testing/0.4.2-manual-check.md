# 0.4.2 manual check: the tray

Status of each step: pending unless marked. Nothing here has been tried by hand yet.

## Windows

- [ ] Aria's icon is in the notification area (perhaps under the ^ overflow) while Aria runs,
  and goes away when Aria quits.
- [ ] Hovering shows "Aria", or "Title – Artist" while something plays.
- [ ] A left click hides the main window; another shows it, restored and in front. A double
  click does the same as one click.
- [ ] A right click opens the menu: Show/Hide Aria, Play/Pause, Next, Previous, Quit Aria. The
  words follow Aria's language, and Play/Pause and Show/Hide follow what is true.
- [ ] Play/Pause, Next and Previous work for a local track and for Spotify.
- [ ] "Minimize to tray" on: minimizing takes Aria off the taskbar and Alt+Tab; the icon brings
  it back. Off: minimizing is as before.
- [ ] "Close to tray" on: the X and Alt+F4 hide Aria and the music keeps playing; "Quit Aria"
  quits, and the settings (window size, volume) are saved as on any quit. Off: the X quits.
- [ ] With the mini-player open, hiding the main window leaves the mini-player playing and
  updating; its button for the main window brings it back.
- [ ] While Aria is hidden, starting Aria again (Start menu) brings the window back.
- [ ] Restarting Explorer (Task Manager) brings the icon back.
- [ ] Shutting Windows down with Aria hidden and "Close to tray" on is not held up.
- [ ] "Restart to update" with "Close to tray" on still installs.

## macOS

- [ ] The icon is in the menu bar; a click opens the menu; every item works.

## Linux

- [ ] KDE Plasma: the icon is in the system tray; a left click shows or hides Aria; the menu
  works.
- [ ] GNOME on X11 without the AppIndicator extension: no icon; with "Minimize to tray" on, Aria
  hides and starting it again brings it back.
- [ ] Wayland: "Minimize to tray" minimizes as usual, "Close to tray" lets the X quit, and a click
  on the icon minimizes or restores Aria.
