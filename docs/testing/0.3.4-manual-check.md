# 0.3.4 manual check

0.3.4 adds hearts on Spotify tracks, "Add to playlist" / "New playlist…", and opens your own
Spotify playlists on Your Library. The automated tests run against a local fake Spotify only;
nobody has tried any of this on a real Spotify account yet. This takes about 10 minutes. Each line
says who verified it:

- **pending**: not verified by anyone yet. Replace it with `user` and the date, or write what went
  wrong.
- **agent**: done by the coding agent.
