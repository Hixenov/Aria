# 0.2.8 manual check

0.2.8 is about what you hear: levelling by ReplayGain and the sleep timer's fade. Both need
ears. It takes about 10 minutes.

Each line says who verified it:

- **pending**: not verified by anyone yet. Replace it with `user` and the date, or write what went
  wrong.
- **agent**: run by the coding agent.

## Before you start

Have at hand tracks with ReplayGain tags (foobar2000, MusicBrainz Picard or loudgain can add
them) from two albums of quite different loudness, and a track without them.

## 1. Volume levelling (5 minutes)
