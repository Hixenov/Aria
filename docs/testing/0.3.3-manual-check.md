# 0.3.3 manual check

0.3.3 lets Spotify play in a small Edge or Chrome window Aria opens, through Spotify's own Web
Playback SDK. The automated tests play the page with a fake browser and a fake Spotify; the page
itself was served by Aria in a browser without copy protection, where it loaded, took its session
and reported Spotify's refusal back. Nobody has heard Spotify play in Aria's window yet. This takes
about 15 minutes and needs Spotify Premium and Edge or Chrome. Each line says who verified it:

- **pending**: not verified by anyone yet. Replace it with `user` and the date, or write what went
  wrong.
- **agent**: done by the coding agent.
