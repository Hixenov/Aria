# Aria 0.4.2: the system tray, implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A tray icon with a menu on Windows, macOS and Linux. "Minimize to tray" works, and a new "Close to tray" switch exists (off by default).

**Architecture:** `crates/aria-app/src/tray.rs` holds the pure parts (events, state, labels, tooltip) and a `TrayBackend` trait. The real one uses tray-icon 0.26.1; tests use a fake. `AriaApp` makes the tray once in `logic_frame`, drains its events, hides or shows the root viewport, cancels the X when "Close to tray" is on, and pushes a `TrayState` whenever it changes.

**Tech Stack:** Rust, egui/eframe 0.37 viewport commands, tray-icon 0.26.1 (muda 0.21.2 menus; ksni 0.3.7 on Linux).

**Spec:** docs/superpowers/specs/2026-11-26-aria-0-4-2-tray-design.md

## Global Constraints

- Project rules: no `unwrap` or `expect` outside tests, no `unsafe`, no `#[allow]`.
- Tests never make a real tray, never touch %APPDATA%\Aria, and never run aria.exe.
- tray-icon 0.26.1 with default features off. Linux and the BSDs use `ksni`. ksni is pinned at
  0.3.7 (0.3.8 is from today).
- `close_to_tray` defaults to `false` and reads leniently. `minimize_to_tray` stays as it is.
- Aria hides only while it has a tray backend. "Quit Aria" in the tray and the updater's install
  always close.
- Showing the window is always `Visible(true)`, `Minimized(false)`, `Focus`, sent to the root
  viewport, and it clears `hidden`.
- Strings in en, ru and hy, plus the KEYS list.

## Review Focus

- The X pressed twice quickly with "Close to tray" on hides the window and never quits. Test:
  `two_close_requests_both_hide`.
- "Quit Aria" while hidden really closes, and the next close request is not cancelled. Test:
  `quit_from_the_tray_closes_for_real`.
- Minimize to tray, then show, then the stale minimized flag on the next frame: no second hide.
  Test: `minimize_hides_once_per_minimize`.
- A failed tray factory: the switches do nothing, and the factory is not tried every frame. Test:
  `without_a_tray_close_and_minimize_stay_as_they_are`.
- A very long title in the tooltip is cut to 127 UTF-16 units on a character boundary. Test:
  `a_long_tooltip_is_cut_at_a_character`.

### Task 2: `tray.rs`

**Files:** Create `crates/aria-app/src/tray.rs`. Modify `crates/aria-app/src/lib.rs` (`pub mod tray;`), the root and aria-app `Cargo.toml` (already done), `deny.toml` (Unlicense).

**Interfaces (produces):**
- `pub enum TrayEvent { Toggle, TogglePlay, Next, Previous, Quit }`. The menu's Show/Hide item and a left-click on the icon are both `Toggle`; the app decides by the window's state.
- `pub struct TrayLabels { show, hide, play, pause, next, previous, quit: String }` with `pub fn new(tr: &Localizer) -> TrayLabels`.
- `#[derive(Clone, PartialEq, Debug)] pub struct TrayState { pub window_shown: bool, pub playing: bool, pub tooltip: String, pub labels: TrayLabels }`.
- `pub fn tooltip(now: Option<&NowPlaying>) -> String`:
  - "Aria" when nothing plays.
  - "Title – Artist" when there is an artist.
  - The title alone when the artist is empty.
  - At most 127 UTF-16 units, cut at a character boundary, ending in "…" when cut.
- `pub trait TrayBackend { fn update(&mut self, state: &TrayState); }`.
- `pub type TrayFactory = Box<dyn Fn(std::sync::mpsc::Sender<TrayEvent>, egui::Context, &TrayState) -> Result<Box<dyn TrayBackend>, String>>`.
- `pub fn system_factory() -> TrayFactory`, the real tray:
  - Menu items `aria-tray-toggle`, `aria-tray-play`, `aria-tray-next`, `aria-tray-previous` and `aria-tray-quit`, with separators as in the spec.
  - The icon is `icon::app_icon()` scaled to 64×64 (Lanczos3).
  - `with_menu_on_left_click(cfg!(target_os = "macos"))`.
  - Tooltip and labels come from the state.
  - The event handlers are set once per process. They send through the given Sender and call
    `ctx.request_repaint()`.
  - A left-click `Click { button: Left, button_state: Up }` is `Toggle` (not on macOS, where
    the click opens the menu).
- `fn menu_event(id: &str) -> Option<TrayEvent>`, pure.

- [ ] Tests:

  - `tooltip_without_artist_is_the_title`.

  - `menu_ids_map_to_events` (unknown gives `None`).
